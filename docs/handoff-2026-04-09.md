## Key Architecture Note
- **Worker containers need BOTH processes**: `restate_worker.py` (port 9080, Restate handler) + `worker_http.py` (port 9081, actual browser automation)
- WorkerSession (Restate VO) → HTTP call to worker_url → worker_http.py → Playwright browser
- Worker URL in `worker_accounts` table must point to HTTP server port (9081), NOT Restate handler port (9080)
